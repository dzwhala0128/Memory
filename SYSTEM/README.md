# SYSTEM｜跨项目记忆管理规范

> **SYSTEM是本GitHub仓库中的“通用记忆规则”分类名，不代表模型的系统提示词或平台级权限。**

本目录只放和具体科研项目无关、对所有项目共同适用的协议。

- [MEMORY_POLICY.md](MEMORY_POLICY.md)：记忆分类、主动写回、事实核验、隐私与安全。
- [SESSION_BOOTSTRAP.md](SESSION_BOOTSTRAP.md)：新会话的读取和启动提示词。

## 原则

1. **通用规则与项目事实分离**：工作方式放在 `SYSTEM/`，项目进展放在 `PROJECTS/<PROJECT>/`。
2. **用户已授权主动同步科研重大事项**：在实际会话中、有可用GitHub工具时，完成重大研究进展后直接更新相关文档；不需每一次额外问授权。
3. **主动同步不是后台服务**：没有交互或没有读取仓库时，不承诺自动运行或跨对话无条件同步。
4. **公开仓库安全优先**：不加入私人信息、密钥、身份识别信息或含敏感内容的原始日志。
5. **尽量最小改动**：更新相关专题，不为一个小变更重写整个仓库。
