# TOPICS｜独立专题知识索引

这里用于未来用户希望记录的**非私人、非单一项目所属**的知识或工作专题，例如跨项目技术方法、公共工具工作流等。

目前尚无独立专题条目；**不预先臆造内容**。

## 分类规则

- `SYSTEM/`：全仓库通用记忆管理规则与跨会话协议。
- `PROJECTS/HERO/`：HerO × TextGrad研究及当前Final项目专属信息。
- `PROJECTS/<OTHER_PROJECT>/`：未来其他独立项目的背景与实验。
- `TOPICS/<TOPIC_ID>/`：有持续复用价值、但不附属于特定项目的非私人专题。

新增专题时，创建 `TOPICS/<TOPIC_ID>/README.md`，并在此索引登记；不把个人隐私、凭据或私人聊天内容放入公开仓库。

若一条知识同时涉及项目和专题，**主记录只保留一处**，另一处用链接引用，避免内容分叉与冲突。
